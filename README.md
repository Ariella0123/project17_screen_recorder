# 🎥 WebScreen Studio - 网页端屏幕录像系统使用说明

WebScreen Studio 是一款基于 Web 原生 API（MediaRecorder、getDisplayMedia、Web Audio API、Canvas）开发的现代化网页端屏幕录像与视频捕捉系统。支持屏幕录制、麦克风与系统音频混合、摄像头画中画（Studio 模式）、本地 IndexedDB 数据库存储以及 PHP 后端同步上传。

---

## 🛠️ 功能特性

1. **屏幕捕捉**：支持全屏、特定应用程序窗口或浏览器标签页录制。
2. **摄像头画中画**：支持独立开启摄像头，可以拖拽悬浮窗位置与调整形状。
3. **Studio 画布合成模式**：利用 HTML5 Canvas 实时将屏幕与摄像头画面合成录制为单条视频。
4. **多路音频混合**：基于 Web Audio API 实现麦克风与系统/标签页音频的实时混音。
5. **双重存储机制**：
   * **本地存储**：基于浏览器 IndexedDB 实现离线保存与快速回放。
   * **云端上传**：支持将录像异步上传至 PHP 服务器保存。
6. **环境变量配置**：通过 `.env` 配置文件自定义上传目录与文件大小限制。

📖 详细使用操作指南
1. 选择录制源
--点击页面上的 “🖥️ 选择屏幕” 按钮。

--在浏览器弹出的对话框中，选择要共享的窗口类型：

    -整个屏幕：适合演示电脑全屏操作。

    -窗口：仅录制某个指定的应用程序（如 PPT、Word 或编辑器）。

    -标签页：仅录制当前的浏览器标签页。

--录制声音提示：若需录制电脑系统声音，请勾选弹窗底部的 “共享系统音频” 选项。

2. 配置摄像头与麦克风（可选）
--点击 “📷 摄像头”：开启悬浮画中画窗口，您可以拖拽悬浮窗改变位置。

--点击 “🎤 麦克风”：开启麦克风人声捕捉。

--点击 “🎬 艺术画中画模式”：启动 Canvas 合成引擎，将屏幕画面与摄像头画中画合成为一体录制。

3. 开始与控制录制
--点击 “🔴 开始录制”：页面计时器开始计时，录制正式启动。

--录制过程中可根据需要点击 “⏸️ 暂停” 或 “恢复”。

--完成后点击 “⏹️ 停止” 结束录制。

4. 查看与管理录像
--录制停止后，系统会自动将视频保存至浏览器的本地 IndexedDB 数据库中；若在 PHP 环境下运行，视频会同步上传至服务器的 uploads/ 目录。

--点击右上角 “📂 录像库”：可查看历史录像列表，支持在线预览、重命名和下载视频。
